# Resort Dom Basílio

Projeto acadêmico de um site institucional para um resort fictício, desenvolvido com foco em organização visual, navegação, responsividade e experiência do usuário.

O **Resort Dom Basílio** apresenta informações sobre hospedagem, lazer, gastronomia, galeria, reservas e contato, simulando a presença digital de um resort real.

## 🌐 Site publicado

Acesse o projeto online:

https://bhsantana.github.io/resort-dom-basilio/

## 📌 Sobre o projeto

O projeto foi desenvolvido inicialmente com tecnologias front-end, com o objetivo de praticar conceitos de desenvolvimento web e construção de interfaces.

Atualmente, o sistema conta com páginas dedicadas para:

- Início
- O Resort
- Acomodações
- Lazer
- Gastronomia
- Galeria
- Reservas
- Contato

## 🛠️ Tecnologias utilizadas

- HTML5

## 🚀 Melhorias da versão otimizada

Nesta atualização, o projeto passou por uma revisão de desempenho, organização e manutenção.

Principais melhorias:

- Conversão das imagens de PNG para WebP.
- Redução do projeto de aproximadamente 28 MB para 2,1 MB.
- Reorganização do CSS por seções.
- Remoção de regras CSS repetidas ou sem utilização.
- Separação do JavaScript em funções específicas.
- Centralização do número utilizado nos links do WhatsApp.
- Correção da estrutura semântica da página inicial.
- Correção da estrutura HTML da galeria.
- Melhorias no menu responsivo, formulários e visualizador de imagens.
- Preservação do conteúdo e da identidade visual do site.
